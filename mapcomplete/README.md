# MapComplete theme: hitchhiking spots

`hitchhiking_spots.json` lets anyone add and check `highway=hitchhiking` nodes in OpenStreetMap
(including Mitfahrbänke, tagged `highway=hitchhiking` + `bench=yes`) with the MapComplete editor,
without knowing OSM tagging. Load it with:

    https://mapcomplete.org/theme.html?userlayout=https://raw.githubusercontent.com/Hitchwiki/hitchhiking-data-standard/main/mapcomplete/hitchhiking_spots.json

Edits go straight to OpenStreetMap and appear on https://maps.hitchwiki.org after its daily sync.
